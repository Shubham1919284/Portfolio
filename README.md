### Projects

#### 1. Room Type Predictor — NYC Airbnb

- End-to-end ML application for classifying NYC Airbnb listings into room types using a tuned Random Forest classifier.
- Built with **Python, Pandas, Scikit-Learn, FastAPI, and Vanilla JavaScript**.
- Implemented a `ColumnTransformer` preprocessing pipeline for numerical and categorical features.
- Handled class imbalance using `class_weight="balanced"`.
- Benchmarked four classifiers and tuned Random Forest using `RandomizedSearchCV`.
- Achieved **85.6% test accuracy** and **0.742 Macro F1-score**.
- Deployed the classification API on **Render**.

[View on GitHub](https://github.com/Shubham1919284/Room-Type-Predictor---NYC-Airbnb) · [Live Demo](https://room-type-predictor-nyc-airbnb-1.onrender.com/)

#### 2. Olist E-Commerce BI Dashboard

- End-to-end data analytics and business intelligence pipeline built on the Brazilian Olist e-commerce dataset.
- Designed a **9-table relational schema** with foreign keys and indexes in PostgreSQL.
- Built a **5-view SQL semantic layer** using a fact/dimension pattern for BI consumption.
- Connected PostgreSQL to Power BI using **DirectQuery**.
- Developed **26 DAX measures** covering KPIs, time intelligence, delivery, reviews, payments, and seller analysis.
- Delivered a **9-page interactive Power BI dashboard** covering sales, customer geography, logistics, reviews, payments, and sellers.
- Analyzed approximately **100K orders**, with headline metrics including **$14.21M revenue, 98.67K orders, 93.23% on-time delivery, and 4.03 average rating**.
